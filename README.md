# Jaden Butler

CS & Cyber Operations student at Cedarville University.

I build tools I use every day in my own terminal, and web apps when I can't
find the thing I want online. Everything runs from [j4den.com](https://j4den.com).
Some of it is finished and some of it is a first draft, and the repos show which.

## Flagship

- [casino-simulator](https://github.com/JadenB9/casino-simulator): a 3D casino you
  walk around with other people. 28 games that pay real odds, and a server that
  holds the money. Built on Cloudflare Durable Objects.
  Play it at [j4den.com/casino](https://j4den.com/casino/).
- [NNvisual](https://github.com/JadenB9/NNvisual): an MLP, a CNN, a small GPT and a
  diffusion model, all running live in the browser. Nothing is a canned animation.
  [j4den.com/nnvisual](https://j4den.com/nnvisual/)
- netmap (private): draws OT/IT network diagrams from YAML and checks the design.
  The Python runs in your browser through Pyodide.
  [j4den.com/netmap](https://j4den.com/netmap/)
- planfortwo (private): a wedding planning platform with checklists, guest list and
  RSVPs, budget, and a website builder. [planfortwo.com](https://planfortwo.com)
- [scripturestack](https://github.com/JadenB9/scripturestack): Bible study with
  semantic search, an atlas, timelines and manuscript data.
  [scripturestack.j4den.com](https://scripturestack.j4den.com)
- Hybrid Sedans (new, source is in the private j4den repo): a 3D comparison of
  every hybrid Camry, Corolla, Civic and Accord trim, plus the Mazda3. It lists
  dealer and APR offers for Ohio and New York.
  [j4den.com/hybrids](https://j4den.com/hybrids/)

## Daily drivers

- [mode-terminal](https://github.com/JadenB9/mode-terminal): the menu my terminal
  opens into. Project jumping, SSH shortcuts and a note pad.
- [customls](https://github.com/JadenB9/customls): a small Go `ls` replacement with
  per-file colors.
- [projectmaker](https://github.com/JadenB9/projectmaker): a TUI that scaffolds new
  projects. Install it with [homebrew-tap](https://github.com/JadenB9/homebrew-tap).

## Security & ML

- [RoadRunner](https://github.com/JadenB9/RoadRunner): a C2 agent in C, written for
  a security-training course at work. Authorized lab use only.
- [NeuralNet](https://github.com/JadenB9/NeuralNet): a YOLOv3 detector with a
  backdoor trigger, plus a fine-pruning defense and dead-neuron analysis.
- [AI-Day-Trader](https://github.com/JadenB9/AI-Day-Trader): seven trading
  strategies behind a hard risk layer, with an LLM reviewing low-confidence
  signals through Alpaca.
- [microlm](https://github.com/JadenB9/microlm): an 840k parameter language model
  in NumPy, with a control surface for editing its weights while it runs.
